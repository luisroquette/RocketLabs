# Suporte

RocketLabs é uma vitrine gratuita e não oferece SLA ou suporte individual
obrigatório.

- **Erro no catálogo:** abra uma issue neste repositório.
- **Erro em um produto:** use o repositório daquele produto.
- **Dúvida de instalação:** leia primeiro o README e a documentação do projeto.
- **Vulnerabilidade ou segredo exposto:** siga [`SECURITY.md`](./SECURITY.md);
  não use uma issue pública.

Issues bem descritas ajudam, mas não garantem prazo, implementação ou
compatibilidade futura.
