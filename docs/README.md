## Como usar · How to use

1. Copie o recurso necessário para seu repositório.
2. Remova o que não se aplica ao projeto.
3. Substitua todos os placeholders e valide os comandos em ambiente limpo.
4. Trate checklists como barreiras de qualidade, não como garantia de segurança.
